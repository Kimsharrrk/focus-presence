# 몰입 트래커 (v1, Mac)

지금 포커스된 앱을 실시간으로 기록하고, 메뉴바와 대시보드로 보여주는 개인용 트래커.
디스코드의 "게임 중" 표시처럼, 내가 무엇에 얼마나 몰입했는지를 눈에 보이게 해서 스스로 자극을 받는 게 목적.

## 실행

```sh
./install.sh              # 빌드 + 로그인 시 자동 실행 등록 (메뉴바에 ● 앱이름 · 시간 표시)
./install.sh --uninstall  # 자동 실행 제거 (기록 데이터는 남음)
./build.sh                # 빌드만
```

메뉴바 항목 → "대시보드 열기" (또는 http://localhost:4317).
필요한 것: Command Line Tools(`swiftc`), Node 22+ (`node:sqlite` 내장 사용, npm 의존성 없음).

## 구조

```
collector/main.swift   Swift 메뉴바 앱. 앱 전환 이벤트 → 세션 기록. 대시보드 서버도 함께 실행
server/server.mjs      Node 서버. SQLite를 읽어 JSON API + 정적 페이지 제공 (127.0.0.1만)
server/public/index.html  대시보드 (현재 상태, 앱별 순위, 타임라인, 7일 막대, 스트릭, 설정)
```

데이터: `~/Library/Application Support/FocusTracker/`
- `tracker.db` — `sessions(id, app, bundle_id, started_at, ended_at)`, 시각은 epoch 초
- `config.json` — `excludedApps`, `focusApps`, `goalHours` (대시보드 설정 화면에서 편집)

개발·테스트용으로 `FOCUS_DATA_DIR`, `PORT` 환경변수로 데이터 위치와 포트를 바꿀 수 있다.

## 결정 사항

- 기록 기준은 **포커스된 앱의 이름만**. 창 제목은 저장하지 않으므로 접근성 권한이 필요 없다.
- 입력이 없어도 센다(읽기·영상 시청도 몰입). 단 **잠금·절전·화면보호기·디스플레이 꺼짐** 동안은 멈춘다.
- 앱 전환 이벤트 기반, 같은 앱이 이어지면 한 세션. 5초마다 `ended_at`을 갱신하므로 비정상 종료돼도 손실은 몇 초.
- 로컬 저장만, 외부 전송 없음. 제외 앱은 앱 이름조차 기록하지 않는다 (기본: 1Password, Bitwarden, 키체인 접근, 암호 앱).
- 스트릭 = "몰입 앱" 목록의 하루 합계가 목표 시간 이상인 날의 연속. 몰입 앱은 설정에서 고르기 전엔 꺼져 있다.
- 앱별 색은 **처음 기록된 순서**로 고정(8색), 9번째 앱부터는 회색 "기타".

## 알려진 한계 (v1)

- 브라우저는 앱 이름만 보여서 YouTube와 Notion 웹이 모두 "Chrome"으로 합쳐진다.
- 앱 이름이 바뀌면(로컬라이즈 등) 다른 앱으로 센다.
- 서버가 5초마다 재시작을 시도하므로, 4317 포트를 다른 프로그램이 쓰고 있으면 계속 실패한다.
- 모바일 시간은 기록되지 않는다.

## 나중에 (구체화 전)
